# 🤖 TG Ads Parser — бот-охотник за заказами

Telegram-бот на Python, который **регулярно проверяет сайты с объявлениями** и
ищет заказы, где люди ищут исполнителя («нужен сайт», «нужен лендинг», «ищу
веб-разработчика», «нужна вёрстка» и т. п.). Как только находит новое подходящее
объявление — **сразу присылает его вам в личку** с кнопкой «Открыть объявление».

Поддерживаемые сайты: **Avito**, **YouDo**, **FL.ru**, **Kwork**, **HH.ru**.

---

## ✨ Возможности

- ⏱ Автоматический парсинг каждые **7–10 минут** (интервал настраивается).
- 🔀 Все сайты опрашиваются **параллельно** (async).
- 🧠 Фильтрация по **ключевым словам** (управляются командами прямо из чата).
- 🗄 **Дедупликация**: одно и то же объявление не приходит дважды (SQLite).
- 🧩 **Расширяемая архитектура** — новый сайт = один новый файл-класс.
- 🔌 Любой сайт можно **включить/выключить** одной строкой в `.env`.
- 🛡 Устойчивость к ошибкам: если сайт «упал» — бот продолжает работать.
- 📝 Логирование в консоль.
- 🔐 Управлять ботом может **только владелец** (по вашему Telegram ID).

## 🚀 Установка

Нужен **Python 3.11+**.

```bash
# 1. Перейти в папку проекта
cd tg_ads_parser

# 2. Создать и активировать виртуальное окружение
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux / macOS:
source .venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Установить браузер для playwright (нужно для Avito и динамических сайтов)
playwright install chromium
```

## 🔑 Как получить токен бота и свой Telegram ID

**Токен бота:**
1. Откройте в Telegram [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`, придумайте имя и username бота.
3. BotFather пришлёт строку вида `123456789:AAE...` — это ваш `BOT_TOKEN`.

**Свой Telegram ID:**
1. Откройте [@userinfobot](https://t.me/userinfobot) и нажмите `/start`.
2. Он пришлёт ваш числовой `id` — это ваш `ADMIN_ID`.

> ⚠️ Обязательно **напишите своему боту `/start`** хотя бы один раз — иначе
> Telegram не даст боту прислать вам сообщение первым.

## ⚙️ Настройка

Скопируйте пример конфигурации и заполните значения:

```bash
# Windows
copy .env.example .env
# Linux / macOS
cp .env.example .env
```

Откройте `.env` и укажите как минимум:

```env
BOT_TOKEN=123456789:AAE...ваш_токен
ADMIN_ID=123456789
```

Остальные параметры (интервал парсинга, включение сайтов, задержки) — по желанию,
у них есть значения по умолчанию.

**Отключить любой сайт** — поставьте `0`:

```env
SITE_AVITO=0    # выключить Avito
SITE_HH=1       # HH.ru включён
```

## 💬 Команды бота

| Команда | Что делает |
|---|---|
| `/start` | Запуск и краткая инструкция |
| `/status` | Сколько сайтов активно, когда был последний парсинг, сколько новых за сегодня |
| `/sites` | Список подключённых сайтов и их статус |
| `/keywords` | Показать текущие ключевые слова |
| `/add_keyword <слово>` | Добавить ключевое слово (например `/add_keyword нужен бот`) |
| `/del_keyword <слово>` | Удалить ключевое слово |
| `/parse_now` | Принудительно запустить парсинг прямо сейчас |

## ➕ Как добавить новые ключевые слова

Прямо в чате с ботом:

```
/add_keyword нужен телеграм-бот
/add_keyword автоматизация
/del_keyword фронтенд
```

Ключевые слова хранятся в базе и применяются сразу при следующем парсинге.
Поиск нечувствителен к регистру и к букве «ё» (`ё` = `е`).

## 🧩 Как добавить новый сайт

Архитектура рассчитана на лёгкое расширение. Нужно 3 шага:

**1. Создайте файл `parsers/mysite.py`** и наследуйтесь от `BaseParser`:

```python
from .base import Ad, BaseParser

class MySiteParser(BaseParser):
    name = "mysite"                 # уникальный ключ
    title = "Мой сайт"              # название для команды /sites

    async def fetch(self, keywords: list[str]) -> list[Ad]:
        html = await self._get_html("https://mysite.ru/orders")
        soup = self.soup(html)
        ads = []
        for card in soup.select(".order-card"):
            link = card.select_one("a.title")
            ads.append(Ad(
                title=link.get_text(strip=True),
                url=link["href"],
                source=self.name,
                description=card.select_one(".desc").get_text(strip=True),
                price=card.select_one(".price").get_text(strip=True),
            ))
        return ads
```

Полезные готовые методы из `BaseParser`:
- `self._get_html(url)` — статическая страница;
- `self._get_json(url)` — JSON-API;
- `self._get_html_dynamic(url)` — рендер через playwright (для JS-сайтов);
- `self.soup(html)` — разбор HTML через BeautifulSoup.

**2. Зарегистрируйте парсер** в `parsers/__init__.py`:

```python
from .mysite import MySiteParser

_ALL = {
    # ...существующие...
    "mysite": MySiteParser,
}
```

**3. (Опционально)** добавьте флаг включения в `config.py` (`SITES_ENABLED`) и в
`.env` (`SITE_MYSITE=1`).

Всё остальное — расписание, фильтрация по ключевым словам, дедупликация и
отправка в Telegram — заработает автоматически.

## ⚠️ Важно про парсинг реальных сайтов

Фактическое состояние источников (проверено на живых сайтах):

| Сайт | Как работает | Статус |
|---|---|---|
| **Kwork** | встроенный JSON `window.stateData` | ✅ работает стабильно |
| **FL.ru** | HTML-парсинг ленты проектов | ✅ работает |
| **HH.ru** | официальный API `api.hh.ru` | ⚠️ endpoint `/vacancies` может отдавать `403` с датацентр-/зарубежных IP; **с домашнего IP (РФ), как правило, работает** |
| **YouDo** | HTML-парсинг | ⚠️ активный антибот, часто `403` — нужен домашний IP или прокси; при смене вёрстки правьте селекторы вверху `parsers/youdo.py` |
| **Avito** | Playwright (headless-браузер) | ⚠️ сильная антибот-защита — может потребоваться прокси; селекторы правятся вверху `parsers/avito.py` |

Полезно знать:

- **HH.ru** — источник самый «правильный» (официальный API). Если видите `403`
  в логах — это блокировка по IP, а не ошибка кода. Проверьте с домашней сети
  или через прокси.
- **Avito** рендерится через JavaScript, поэтому нужен `playwright install chromium`.
- **YouDo, FL.ru** парсятся по HTML — сайты **периодически меняют вёрстку**,
  поэтому CSS-селекторы вынесены в **константы вверху каждого файла**. Для FL.ru
  можно включить рендер через playwright флагом `USE_DYNAMIC = True`.
- **Kwork** читается из встроенного JSON — это устойчивее CSS-селекторов.
- Если какой-то сайт заблокирован по IP или сменил разметку — бот **не падает**,
  а пропускает его в этом цикле и пишет предупреждение в лог.
- Соблюдайте правила сайтов и здравую нагрузку: в коде уже есть ротация
  User-Agent и случайные задержки между запросами (`REQUEST_DELAY_MIN/MAX`).

> 💡 **Про прокси.** Для стабильной работы HH/YouDo/Avito из любого места можно
> добавить прокси. Быстрый способ — задать переменные окружения `HTTP_PROXY` /
> `HTTPS_PROXY` (их подхватывает aiohttp), а для Playwright — параметр `proxy=` в
> `browser.launch()` внутри `parsers/base.py`.

Если какой-то сайт временно недоступен или сменил разметку — бот **не упадёт**,
а просто пропустит его в этом цикле и залогирует предупреждение.

## 🛠 Частые проблемы

| Проблема | Решение |
|---|---|
| `BOT_TOKEN не задан` | Заполните `.env` (см. `.env.example`) |
| Бот не пишет мне | Напишите боту `/start` в личке хотя бы раз |
| Avito ничего не находит | Выполните `playwright install chromium`; возможно, нужен прокси |
| YouDo/FL.ru/Kwork пусто | Сайт сменил вёрстку — поправьте селекторы в начале их файлов |
| Приходят чужие объявления | Уточните ключевые слова через `/keywords` и `/del_keyword` |
